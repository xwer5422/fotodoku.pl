 # FotoDoku.pl — Generator zdjęć do dowodu, paszportu i prawa jazdy (100% lokalnie)
    
    🌐 **Strona:** https://fotodoku.pl/

    **FotoDoku.pl** to bezpłatne narzędzie webowe działające całkowicie po stronie
    przeglądarki (**Zero-Server / Client-Side AI**). Pozwala przygotować zdjęcie
    biometryczne zgodne z wymogami **MSWiA** oraz normą **ICAO 9303** bez wysyłania pliku
    na jakikolwiek serwer.

    ## Funkcje
    - **100% prywatności:** detekcja twarzy (MediaPipe), usuwanie tła AI do czystej bieli
    (`#FFFFFF`) i kadrowanie odbywają się wyłącznie w pamięci urządzenia.
    - **Dwa gotowe formaty wyjściowe za 0 zł:**
      - pojedynczy plik cyfrowy do e-wniosków (**gov.pl / mObywatel**),
      - arkusz **10×15 cm (300 DPI)** z 8 zdjęciami **35×45 mm** do taniego wydruku w
      fotokiosku (np. Rossmann, dm, CEWE).
